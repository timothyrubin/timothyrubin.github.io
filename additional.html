Research Code

I have some publicly available code relating to my work on multi-label document classification (Dependency-LDA, Prior-LDA), and unsupervised learning of functional brain regions using fMRI data (Generalized Correspondence-LDA), available on my GitHub profile.

  • DependencyLDA
    Matlab (and C) implementation of Dependency-LDA, Prior-LDA and Flat-LDA models for multi-label document classification. See Rubin et al. (2012), Machine Learning.
  • python_gclda
    Python implementation of Generalized Correspondence-LDA. See Rubin et al. (2016), NIPS.

Note that all of this code was written solely for research purposes and should not be treated as production software.
